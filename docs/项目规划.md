# ApexScrolling — 纯文字反算法知识信息流 App

> 本文件是项目立项时确认的规划（v1 定稿），实现以此为准。

## Summary
Flutter 双端（Android+iOS）手机 App，定位「替代短视频的纯文字信息流」：上滑即随机刷到一张极简文字卡片——学术冷门词条、哲学观点、经典选段、短篇/散文、实用技能教程。无账号、无后端、无算法推荐，纯客户端直连开放资源；卡片态仿抖音图文的沉浸文字排版，点按展开后进入完整阅读模式。

## 内容源与卡片类型（v1 六源，中英混合，全部纯文字）
| 卡片 | 来源 | 抽取机制 |
|---|---|---|
| 冷门学术词条 | 中文/英文维基百科 | 不用全站随机：先经 Wikidata SPARQL 限定学术领域（哲学、科学史、语言学、数学等）且**站点链接数 ≤ 100**（保证足够冷门），再取条目导语渲染 |
| 哲学观点 | 斯坦福哲学百科 SEP + 维基百科哲学类冷门词条 | SEP 抓条目导语前 2–3 段（英文）；中文走上行的哲学类冷门词条 |
| 哲学/经典书籍选段 | 古登堡计划（Gutendex）+ 中文维基文库 | 预置公版书清单（《沉思录》、柏拉图、尼采早期译本；《老子》《庄子》《论语》等），随机抽书→随机切 300–600 字选段 |
| 短篇小说/散文 | 中文维基文库 + 古登堡精选清单 | 预置公版作者清单（鲁迅、朱自清、郁达夫；Chekhov、Poe 等），随机抽篇→随机取一段完整场景（按段落边界切，不腰斩句子） |
| 实用技能教学 | wikiHow（中/英文站） | 取步骤化正文，渲染为编号步骤卡；按 CC BY-NC-SA 在卡片底部署名 |
| 诗词名句 | 今日诗词 API（v1.jinrishici.com） | 诗句+出处，卡片最短，作节奏调剂 |

- 信息流按权重随机抽源，六源均等；设置中可逐源开关。
- 词条卡内维基内链点击后在当前位置插入新卡（兔子洞），深度上限 5 层。
- 预取后 3 张；已看卡片可回滑；单源失败自动换源重抽，连续失败 60s 熔断；无网时显示缓存卡片并提示。

## 卡片视觉与交互（核心体验）
- **卡片态（默认）**：
  - 顶部**粗体标题**（来源小字署名在标题下方）。
  - 正文自上而下正常排布，**向底部渐变透明淡出**（类似抖音图文文字渐隐），示意“下面还有内容”，单屏固定、卡片内不可滚动。
  - 卡片内不出现任何图片、按钮、红点；仅标题+正文+淡出渐变。
- **手势规则**：
  - **上滑**（未展开时）→ 直接切下一张卡片；下滑 → 回到上一张。
  - **点击正文中央区域** → 该卡进入**展开态**：正文完整呈现，卡片内可上下滚动阅读全文。
  - 展开态英文正文支持**双击单词翻译**；仅发送被选中的单词，不上传整篇正文。
  - 展开态中上滑先滚动正文，**滑到正文底部后继续上滑则切下一张**（衔接滑动惯性，不打断刷的节奏）；再点击中央收起回卡片态。
- **阅读排版**：默认衬线字体（中文霞鹜文楷/思源宋体，英文 Georgia），行距 1.8、字号三档可调、深色/浅色主题（跟随系统，可手动覆盖）。
- 来源署名（如 wikiHow CC BY-NC-SA）固定在卡片底部渐变区内小字显示。

## 技术实现
- Flutter 3.x + Riverpod；`PageView` 无限下滑 + 预取；卡片态/展开态为同一 Widget 的两种布局状态（展开态切换为内滚 `SingleChildScrollView` 并启用滑到底透传切卡手势）。
- 渐变淡出用 `ShaderMask` 实现，展开态移除。
- 每源一个 Adapter（统一 `Future<TextCard>` 接口）+ 每卡型一个纯文字 Widget。
- 隐私：无账号、无埋点、无自建服务器；设置存本地 SharedPreferences；Wikidata/API 请求带规范 User-Agent。
- 文本清洗：统一剥离 HTML/模板残留、规范换行与空段；古登堡文件处理 GBK/UTF-8 编码差异。

## Test Plan
- 单元测试：六个 Adapter 各用 fixture 验证解析（缺摘要、超长正文、特殊字符、编码异常）；Wikidata 冷门筛选逻辑（sitelinks ≤ 100 阈值边界）。
- Widget 测试：上滑切卡 / 下滑回看、点击中央展开与收起、展开态内滚动、滚到底继续上滑切下一张、渐变淡出仅卡片态显示、源开关生效、断网 fallback。
- 集成验收：真机连续上滑 50 张无卡顿白屏；任一源宕机流不中断；展开长文（>10 屏）滚动流畅；冷启动至首卡 < 2s。

## Assumptions
- 「画面极简、纯文字」= v1 移除原 Met 名画图片源，全部内容文字呈现。
- 展开态收起方式默认为“再点中央”；底部署名区不响应展开点击，避免误触。
- sitelinks ≤ 100 放宽后词条面显著扩大，仍以学术领域限定保证质量；设置中提供严格/宽松两档（≤ 20 / ≤ 100），默认宽松。
- wikiHow 内容为 CC BY-NC-SA，App 免费 non-commercial 使用合规，卡片内附署名；若不可接受可仅关闭该源。
- SEP 无官方 API，v1 直接抓取条目 HTML 解析导语。
