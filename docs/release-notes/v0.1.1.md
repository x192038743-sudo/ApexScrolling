## ApexScrolling v0.1.1 测试版

替代短视频的**纯文字信息流** App：上滑随机刷到一张极简文字卡片——冷门学术词条、哲学观点、
经典选段、短篇小说/散文、实用技能、诗词名句。无账号、无后端、无算法推荐。

### 本版重点

- **修复**：预取在 Provider 销毁后仍访问 `ref`，会抛 `UnmountedRefException`
  （由 Android 真机验收用例发现）。
- **改进**：「实用技能」源在 wikiHow 不可达时退回维基教科书，现只保留
  「能跟着做」的实用主题（食谱/急救/手工/园艺/摄影…），并在会话内去重。

### 安装包

| 平台 | 文件 | 说明 |
|---|---|---|
| Android | `ApexScrolling-v0.1.1-beta-universal.apk` | 任意机型（arm64 / armv7 / x86_64） |
| Android | `ApexScrolling-v0.1.1-beta-arm64-v8a.apk` | 绝大多数现代手机，体积更小 |
| Android | `ApexScrolling-v0.1.1-beta-armeabi-v7a.apk` | 老 32 位机型 |
| iOS | `ApexScrolling-v0.1.1-beta-unsigned.ipa` | 未签名，用 Sideloadly + Apple ID 签名安装 |

`SHA256SUMS.txt` 为上述产物的校验值。

```bash
# Android
adb install -r ApexScrolling-v0.1.1-beta-universal.apk

# iOS：Sideloadly 里选择 .ipa，填 Apple ID，装完在
# 设置 → 通用 → VPN与设备管理 信任证书；iOS 16+ 还需打开开发者模式
```

> Android 使用 debug 签名（测试用途）；iOS 为未签名 IPA。上架前需替换为正式签名。
> 免费 Apple ID 的证书 7 天过期，到期重装即可。

### 验证记录

- `flutter analyze` 无告警；49 个单元 / Widget 测试全部通过。
- Android 设备端（API 30）端到端验收通过：冷启动出卡 → 上滑切卡 → 展开 → 内滚不误切卡 →
  滑到底继续上滑切卡 → 收起 → 设置页版本号。
- 连续上滑 **50 张**：总耗时 47s，平均 0.95s/张，最慢 1.23s，六个内容源均有出卡，无白屏无崩溃。
- 真实网络冒烟：六个数据源全部可用（受限网络下 wikiHow 自动回落维基教科书）。

### 已知问题

- 首次冷启动若抽到词条源，需等一次 Wikidata 查询（约 10–15s），之后候选池复用恢复 1–2s。
- 受限网络下 `*.wikipedia.org` 不可达，维基正文已改走 `api.wikimedia.org`；
  若该域也被拦截，词条源会熔断并由其他源接管。
- 应用图标与启动底色已定制，但尚未做截图/商店素材。
