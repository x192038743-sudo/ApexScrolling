# 数据源接入与合规说明

## 1. 六个内容源的实际接入方式

| 卡片类型 | 线上接口 | 说明 |
|---|---|---|
| 冷门学术词条 | `POST https://query.wikidata.org/sparql` + `GET https://api.wikimedia.org/core/v1/wikipedia/{lang}/page/{title}/html` | SPARQL 限定 12 个学术类目（学科 / 术语 / 定理 / 数学概念 / 哲学概念 / 悖论 / 哲学立场 / 思想实验 / 社会学概念 / 语言学概念 / 物理学概念 / 政治哲学）并按 `wikibase:sitelinks ≤ 100`（严格档 20）筛选，再用 `ORDER BY RAND()` 取候选池；**一次查询取 12 条候选缓存复用**，避免连续出卡都等 SPARQL |
| 哲学观点 | `GET https://plato.stanford.edu/contents.html` → 随机条目页 | 目录页会话内缓存，条目页解析 `<h1>` 后第一个小节标题之前的 2–3 段导语 |
| 经典书籍选段 | 中文：`zh.wikisource.org/w/api.php?action=parse`；英文：`gutendex.com/books` + 古登堡纯文本 | 文库用 `action=parse`（非 `prop=extracts`，因为文库正文多由模板嵌入，extracts 会返回空）；古登堡优先 `text/plain; charset=utf-8`，下载后切掉项目说明头尾 |
| 短篇小说 / 散文 | 同上（文库预置篇目 + 古登堡按作者检索） | 随机取一段 300–600 字的完整段落 |
| 实用技能教学 | 主：`zh.wikihow.com` / `www.wikihow.com` 的 MediaWiki API；备：`zh.wikibooks.org` 前缀检索 `食谱/` 等主题 | wikiHow wikitext 的 `#` 一级编号即步骤；不可达时退回维基教科书，优先「有 ≥2 条编号步骤」的教程页 |
| 诗词名句 | 随包 `assets/poems/*.json`；网络兜底 `GET https://v1.jinrishici.com/all.json` | 优先展示完整分行诗词；选集不可用时使用今日诗词的诗句 + 出处 + 作者 |

## 2. 网络受限环境的适配（重要）

实测中国大陆网络下 `*.wikipedia.org`、`gutendex.com` 等域名可能不可达，而下列域名稳定可用，因此实现上做了针对性选择：

- **维基百科正文**统一走 `api.wikimedia.org`（Wikimedia 官方 REST），不依赖 `zh.wikipedia.org`。
- **维基文库 / 维基教科书**走 `*.wikimedia.org`/`*.org` 的 MediaWiki Action API。
- **wikiHow 完全不可达时**自动切换维基教科书源，卡片署名与授权随之切换。
- 信息流按随机轮换队列公平抽源，避免响应最快的诗词接口长期垄断；任一源失败都会**自动换源重抽**；同一源连续失败 2 次后**熔断 60 秒**；全部失败时展示**本地缓存卡片**并提示。

## 3. 授权与合规

| 来源 | 授权 | App 内署名 |
|---|---|---|
| 维基百科 | CC BY-SA 4.0 | 「维基百科 · CC BY-SA 4.0」 |
| 维基文库 / 维基教科书 | CC BY-SA 4.0 | 「维基文库 · CC BY-SA 4.0」/「维基教科书 · CC BY-SA 4.0」 |
| wikiHow | CC BY-NC-SA 3.0 | 「wikiHow · CC BY-NC-SA 3.0」 |
| 古登堡计划 | 公有领域 | 「古登堡计划 · 公有领域」 |
| 斯坦福哲学百科 | 个人阅读使用 | 「Stanford Encyclopedia of Philosophy」 |
| 今日诗词 | 官方 API | 「今日诗词」 |

其他合规设计：

- 无账号、无埋点、无自建服务器；设置与缓存只存在本机 SharedPreferences。
- 请求带可识别 UA（**ASCII**，`ApexScrolling/1.0`）。注意 HTTP 头不允许非 ASCII 字符，UA 里写中文会直接导致请求失败。
- wikiHow 为 NC 授权：App 需保持免费、非商业；不接受该授权时可在设置中关闭该源。
- 缓存仅保存**卡片文本**（含署名），不保存任何用户行为数据。
