# ApexScrolling 测试版（v0.1.0）说明

## 1. 这是一版什么版本

- 版本号：`0.1.0+1`（测试版 / beta），Flutter 3.35 双端工程，本次交付 **Android release APK**。
- 定位：功能完整、可日常试用的第一个测试版；内容与交互按《项目规划》v1 全量实现。
- 签名：使用 Flutter 模板的 **debug keystore** 签名（便于直接安装试用），**上架前必须换成正式签名**。

## 2. 安装

APK 产物（仓库内已放好一份，见 `dist/`；`build/` 下的原始产物同名）：

| 文件 | 体积 | 适用 |
|---|---|---|
| `dist/ApexScrolling-v0.1.0-beta-universal.apk` | 45.7MB | 任意机型（含 arm64 / armv7 / x86_64） |
| `dist/ApexScrolling-v0.1.0-beta-arm64-v8a.apk` | 16.3MB | 绝大多数现代手机 |
| `dist/ApexScrolling-v0.1.0-beta-armeabi-v7a.apk` | 13.9MB | 老 32 位机型 |

校验值见 `dist/SHA256SUMS.txt`。

```bash
# 用 adb 安装（手机开启「USB 调试」）
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

也可以直接把 APK 传到手机点击安装（需在系统设置里允许「安装未知来源应用」）。

最低系统版本沿用 Flutter 默认（Android 5.0 / API 21+），目标 API 36。

## 3. 首次打开会看到什么

1. 冷启动后先取第一张卡。若首个抽中的是「冷门词条」，需要等一次 Wikidata 查询（约 10–15 秒），期间会显示加载页；其余源通常 1–3 秒。之后候选池复用，出卡明显变快。
2. 卡片态：顶部粗体标题 + 小字来源署名，正文向下渐隐；**上滑下一张、下滑上一张**。
3. **轻点卡片**进入展开态，正文可滚动；**滑到正文底部继续上滑**直接切下一张；**再轻点一次**收起。
4. 词条卡展开后底部会出现「延伸词条」链接，点击即在当前位置插入下一层卡片（兔子洞，最多 5 层）。
5. 右上角 `≡` 打开设置：逐源开关、字号三档、主题、词条冷门度（≤100 / ≤20）、清除缓存。

## 4. 建议重点验证的项

| 项 | 期望表现 |
|---|---|
| 连续上滑 50 张 | 不白屏、不卡顿；每张都能正常出卡 |
| 任一源不可用 | 信息流不中断，自动换源；顶部出现轻提示 |
| 断网刷 | 显示本地缓存卡片，并提示「网络不可用 · 正在浏览缓存卡片」 |
| 展开长文（>10 屏） | 滚动流畅，滑到底继续上滑可切下一张 |
| 字号三档 / 深浅主题 | 立即生效，重启后保持 |
| 逐源开关 | 关掉的源不再出现；至少保留一个源 |
| 冷启动首卡 | 非词条源 1–3 秒内出卡 |

## 5. 已知问题与限制

1. **wikiHow 在部分网络不可达**（本机开发环境即如此），此时「实用技能」卡改由中文维基教科书提供，形态是「简介 + 编号步骤」，署名与授权同步切换为 CC BY-SA 4.0。
2. **维基百科主域 `zh.wikipedia.org` 在部分网络不可达**，因此正文统一走 `api.wikimedia.org`；若该域也被拦截，词条源会熔断并由其他源接管。
3. 词条卡的正文是条目**导语**（1–4 段），内容量小于小说/散文卡，属设计如此。
4. 古登堡书籍全文按需下载（数百 KB–1MB），首次抽到某本书时略慢，之后走内存缓存。
5. 测试版使用 debug 签名、未做图标与启动图定制，属于预期状态。

## 6. 在别的机器上重新构建

```bash
flutter config --android-sdk <你的 Android SDK 路径>
flutter config --jdk-dir <JDK 17 路径>
flutter build apk --release
```

构建相关的两点说明：

- `android/gradle.properties` 里的 `apex.cnMirrors=true` 会让 Gradle 优先走国内镜像（华为云 / 腾讯云 / 阿里云）解析 AGP、AndroidX、Kotlin 插件；如果你的网络能直连 `maven.google.com`，把它改成 `false` 即可走官方仓库。
- 若你的网络需要 Flutter 官方资源镜像，构建前设置：`set FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn`。首次构建还会自动下载 Gradle 发行包与 Android SDK 组件（含 NDK，若工程中保留 `ndkVersion`）。
